IL BATE PAPO — PACOTE DE PUBLICAÇÃO

SITE OFICIAL
https://il-bate-papo.github.io/

PUBLICAÇÃO NO GITHUB PAGES
1. Envie TODOS os arquivos deste ZIP para a RAIZ do repositório il-bate-papo.github.io.
2. Não envie o ZIP como um único arquivo.
3. O index.html deve ficar na raiz do repositório.
4. Depois de publicado, confirme o endereço https://il-bate-papo.github.io/

SEO / REDES SOCIAIS
- Canonical configurado para a raiz oficial.
- Open Graph configurado para WhatsApp, Facebook e serviços compatíveis.
- Twitter/X Card configurado.
- Imagem social: il-bate-papo-preview.jpg (1200x630).
- robots.txt e sitemap.xml configurados para a raiz oficial.
- Dados estruturados Schema.org incluídos.
- Manifest PWA configurado.

GOOGLE ANALYTICS / SEARCH CONSOLE
Este pacote NÃO contém um ID antigo do Google Analytics.
Depois que o site estiver publicado, crie/confirme a propriedade correta do IL Bate Papo e então adicione o ID novo.
No Search Console, use a URL oficial acima e envie /sitemap.xml.

INSTALADORES
Este ZIP é o pacote WEB/PWA pronto para publicação.
Ele NÃO contém APK/AAB porque o ZIP recebido não possui um projeto Android/Gradle nem uma chave de assinatura própria do IL Bate Papo.
Para distribuição Android serão gerados separadamente:
- APK assinado: instalação direta e envio por WhatsApp/Amazon, conforme requisitos da loja.
- AAB assinado: Google Play.
Nunca publique senhas, keystore ou chaves privadas no GitHub.

Windows: o PWA pode ser instalado pelo navegador compatível; um empacotamento dedicado pode ser preparado depois.
iPhone/iPad: PWA pode ser adicionado à Tela de Início. Publicação nativa iOS exige assinatura/distribuição Apple.
